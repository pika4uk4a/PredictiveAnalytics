# Лабораторная работа №3 — Классификация и прогнозирование метеоданных

Двухэтапная система анализа временных рядов на данных open-meteo (2019–2025) по 6 городам России.

* **Этап 1 — Классификация.** По 30-дневному окну метеопараметров определяется тип климата (умеренно-континентальный / субтропический / резко-континентальный).
* **Этап 2 — Прогнозирование.** Для каждого города обучается отдельная модель прогноза температуры на горизонт 30 дней. Этапы объединяются в единый пайплайн `WeatherPipeline`.

## Что внутри ноутбука

| Раздел | Что делается |
|---|---|
| 2.1 EDA | визуальный анализ рядов, распределения, Q-Q, корреляции, пропуски, ADF, ACF/PACF, STL |
| 2.2 Признаки | временные/циклические признаки, лаги, скользящие статистики, климатическая норма, PCA |
| 2.3 Классификация | обучение 4 специализированных TS-классификаторов: **ROCKET, MiniRocket, TimeSeriesForest, RISE** (через `aeon`) |
| 2.4 Оценка классификации | Accuracy / Precision / Recall / F1 (macro и weighted), confusion matrix, ROC-AUC OvR, помесячная точность, важность каналов через permutation |
| 2.5 Прогноз | по городу: Ridge / RandomForest / GradientBoosting–LightGBM в зависимости от типа климата |
| 2.6 Оценка прогноза | MAE / RMSE / MAPE / WAPE / R² / directional accuracy, анализ остатков (Shapiro–Wilk, Jarque–Bera, Ljung–Box, Durbin–Watson, BP) |
| 2.7 Пайплайн | `WeatherPipeline.run(city_df, city_name)` — классификация + прогноз |
| 2.8 Документация | сводная таблица, итоговый дашборд, выводы |

## Сравнение моделей классификации

В ноутбуке обучаются и сравниваются ровно 4 модели:

* **ROCKET** — случайные свёрточные ядра (PPV + Max);
* **MiniRocket** — детерминированные ядра, ~75× быстрее ROCKET;
* **TimeSeriesForest** — деревья на случайных интервалах;
* **RISE** — спектральные признаки из случайных интервалов.

Результаты сводятся в таблицу (Accuracy / F1-macro / F1-weighted / ROC-AUC) и в столбчатый график на итоговом дашборде, по ним выбирается лучшая модель для использования в пайплайне.

## Данные

Файлы вида `{Город}_{YYYY}-01-01_{YYYY}-12-31.parquet` за 2019–2025 для шести городов:
Москва, Санкт-Петербург, Сочи, Геленджик, Благовещенск, Находка.

Колонки: `temperature_2m`, `relative_humidity_2m`, `precipitation`, `rain`, `snowfall`, `weathercode`, `wind_speed_10m`, `surface_pressure`.
