# Лабораторная работа 2: Виртуальный сенсор концентрации

## Что входит в работу

- `lab2_virtual_sensor.ipynb` — полный пайплайн решения: загрузка, синхронизация, feature engineering, обучение, оценка и интерпретация.
- `data_train.csv`, `target_train.csv` — обучающие данные.
- `data_test_small.csv`, `target_test_small.csv` — тестовые данные.
- `requirements.txt` — зависимости Python для запуска ноутбука.

## Требования

- Python 3.10+ (рекомендуется 3.10 или 3.11).
- `pip` и виртуальное окружение (`venv`).

## Установка и запуск

1. Перейдите в папку лабораторной:

```bash
cd lab2
```

2. Создайте и активируйте виртуальное окружение:

```bash
python -m venv .venv
```

Windows (PowerShell):

```bash
.\.venv\Scripts\Activate.ps1
```

Linux/macOS:

```bash
source .venv/bin/activate
```

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Запустите Jupyter:

```bash
jupyter notebook
```

5. Откройте `lab2_virtual_sensor.ipynb` и выполните ячейки сверху вниз.

## Что делает пайплайн

1. Загружает телеметрию и лабораторные замеры.
2. Синхронизирует признаки с целью с учетом задержки измерений.
3. Строит признаки (лаги, статистики, оконные агрегаты).
4. Обучает несколько моделей (`Ridge`, `Random Forest`, `LightGBM` или `GradientBoosting` как fallback).
5. Сравнивает качество на тесте.
6. Выполняет интерпретацию признаков (`Permutation Importance`, `SHAP`) и анализ остатков.

## Как интерпретировать результаты

Основные метрики (чем лучше):

- `MAE` — средняя абсолютная ошибка, ниже лучше.
- `RMSE` — штрафует крупные ошибки сильнее, ниже лучше.
- `R2` — доля объясненной вариации, выше лучше (ближе к 1).

Дополнительно:

- График `Факт vs Прогноз` показывает, насколько модель повторяет динамику концентрации.
- Анализ остатков помогает проверить систематические ошибки и автокорреляцию.
- `Permutation Importance` и `SHAP` показывают, какие признаки сильнее влияют на прогноз.

Практическое правило выбора модели:

- Базово ориентироваться на минимум `RMSE/MAE`.
- Если метрики близки, выбирать модель с более устойчивым поведением на графиках остатков и понятной интерпретацией признаков.

## Примечания

- В ноутбуке `LightGBM` используется при наличии библиотеки `lightgbm`; иначе автоматически используется `GradientBoostingRegressor` из `scikit-learn`.
- Все CSV должны находиться в папке `lab2` рядом с ноутбуком.
